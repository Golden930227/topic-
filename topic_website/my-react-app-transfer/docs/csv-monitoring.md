# CSV 量測頁

`/cnn-monitor` 和獨立 CNN 頁透過 `/api/cnn` 讀取 Windows 的
`D:\CSV接收區`，不查詢 SQL。AI 頁維持原有 SQL 來源。

FastAPI 啟動一個共用背景讀取器，每秒依檔案修改時間由新到舊檢查 `.csv`。
大小與修改時間跨兩次檢查保持不變、讀取前後一致、整份 CSV 通過欄位與數值
檢查後才發布；失敗保留最後成功結果並重試。既有接收器使用 `.part` 寫入後
原子更名，請沿用此寫法。其他寫入器若長時間暫停在完整列邊界，單憑檔案
狀態無法保證寫入結束，也應使用 `.part` 再更名。

量測保留最近 200 筆，表格顯示最近 15 筆、最新在上。`Vo` 對應 `vout2`，
80 Ω 負載的估算電流／功率沿用 `Vo/80`、`Vo²/80`；`run_id` 不當成電流。
無可信電流或轉速時顯示未提供。圖表依 CSV 接收順序排列，不把裝置相對毫秒
換成日期。`received_at`／`接收時間` 原字串保留；`loadedAt` 是成功切換新檔
時的 UTC+08:00 時間，同檔輪詢或失敗不會更新。測試來源依檔名、run_id、
data_source 等標記，CSV 讀入不代表裝置心跳。

登入驗證沿用既有 middleware；訪客只取得既有量測白名單、原始接收時間與
顯示所需的檔名／讀入時間，不取得原始 JSON、完整路徑及裝置批次資訊。
可透過 `WINDMIND_CSV_DIR` 覆寫資料夾。使用既有單 worker 啟動方式，共用
一份讀取結果；多 worker／多主機各自維護快照。本次不修改外部 CSV 接收器。
